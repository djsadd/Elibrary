# Быстрая загрузка статей/книг для редакторов

## Обзор

Реализован новый endpoint `POST /catalog/books/quick` для максимально быстрой загрузки статей, верстанных файлов, названий и других материалов без прохождения всех этапов валидации.

## Что было добавлено

### 1. Новая схема `QuickBookCreate` 
**Файл:** [app/schemas/book.py](app/schemas/book.py#L32-L60)

Минимальная схема для быстрого создания статей с требуемыми полями:

**Обязательные поля:**
- `title` (str) - Название статьи/книги
- `file_id` (str) - ID загруженного файла
- `formats` (List[str]) - Форматы (EBOOK, AUDIOBOOK, VIDEOBOOK и т.д.), по умолчанию ["EBOOK"]

**Опциональные поля:**
- `year` - Год публикации
- `lang` - Язык (ru, en и т.д.)
- `pub_info` - Информация об издании
- `summary` - Краткое описание
- `cover` - Base64 обложка или URL
- `cover_file` - Путь к файлу обложки
- `authors` - Список авторов
- `subjects` - Категории/предметы
- `isbn` - ISBN (при наличии)
- `edition` - Издание
- `page_count` - Количество страниц
- `available_copies` - Доступное количество копий (по умолчанию 1)
- `is_public` - Публичный доступ (по умолчанию True)

### 2. Новый endpoint для быстрой загрузки
**Файл:** [app/api/catalog_books.py](app/api/catalog_books.py#L290-L351)

```
POST /catalog/books/quick
```

#### Параметры запроса

JSON body с типом `QuickBookCreate`

#### Ответ

Возвращает полный объект `BookOut` с созданной книгой

#### Код авторизации

Доступен для ролей:
- `editor` - редактор
- `admin` - администратор
- `librarian` - библиотекарь

**Статус код:** 201 Created

#### Пример использования

```bash
curl -X POST "http://localhost:8002/catalog/books/quick" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Название статьи",
    "file_id": "abc123def456.pdf",
    "formats": ["EBOOK"],
    "year": "2024",
    "lang": "ru",
    "summary": "Краткое описание статьи",
    "authors": ["Иван Петров", "Мария Сидорова"],
    "subjects": ["Технология", "Образование"]
  }'
```

## Особенности реализации

1. **Минимальные требования** - Редактор может загружать статьи, указав только название и ID файла
2. **Автоматическое создание авторов и категорий** - Если указанные авторы или категории не существуют, они автоматически создаются
3. **Индексация в поиске** - Новая статья автоматически индексируется в поисковом сервисе
4. **Обработка ошибок** - Надлежащая обработка ошибок целостности данных и внутренних ошибок
5. **Роли доступа** - Endpoint доступен только для редакторов, администраторов и библиотекарей

## Различие между обычным и быстрым созданием

### POST /catalog/books (обычное создание)
- Требуется полная информация о книге
- Применяются все валидации
- Используется для систематического добавления в библиотеку

### POST /catalog/books/quick (быстрое создание)
- Минимум требуемых полей (название + файл + форматы)
- Оптимизировано для быстрой загрузки
- Используется редакторами для оперативного добавления материалов
- Автоматически создает отсутствующих авторов и категории
- Только для ролей: editor, admin, librarian

## Технические детали

- **Язык:** Python 3.x
- **Framework:** FastAPI
- **ORM:** SQLAlchemy
- **Файлы изменения:**
  - [app/schemas/book.py](app/schemas/book.py) - добавлена схема `QuickBookCreate`
  - [app/api/catalog_books.py](app/api/catalog_books.py) - добавлен endpoint `quick_create_book()`

## Функциональность

Endpoint выполняет следующие операции:
1. Валидирует входные данные согласно схеме `QuickBookCreate`
2. Проверяет права доступа (требуется роль editor/admin/librarian)
3. Создает объект Book в БД
4. Автоматически создает отсутствующих авторов
5. Автоматически создает отсутствующие категории
6. Коммитит транзакцию в БД
7. Отправляет асинхронную задачу индексации в поисковый сервис
8. Возвращает полный объект созданной книги

## Обработка ошибок

- **400 Bad Request** - Если возникла ошибка целостности данных (например, дублирование)
- **401 Unauthorized** - Если отсутствует или невалидный токен
- **403 Forbidden** - Если пользователь не имеет необходимой роли
- **500 Internal Server Error** - Внутренняя ошибка сервера
